隐私政策

1. 引言

ASN Lab（“我们”）致力于保护您的隐私。本隐私政策说明了我们在您使用我们的网站（asnlab.org）和服务时收集哪些信息、如何使用这些信息，以及您对这些信息所享有的权利。

2. 我们收集的信息

2.1 购买订单

当您通过我们的网站提交购买订单时，我们会收集以下信息：

  • 联系信息：姓名、电子邮件地址、公司名称和电话号码。
  • 账单地址：物理地址和邮政编码。
  • 产品选择：您选择的编译器许可证（C、C++、Java、C#、Go）。
  • 支付信息：您的支付由我们的第三方支付服务商 Stripe 处理。我们不会存储您的完整信用卡或支付方式详情。Stripe 向我们提供会话标识符和支付状态。

2.2 免费试用申请

当您申请免费的 30 天评估许可证时，我们会收集：

  • 姓名
  • 职位
  • 工作邮箱地址
  • 公司或组织名称
  • 电话号码（可选）
  • 感兴趣的产品（C、C++、Java、C#、Go）

2.3 许可证使用

当您使用已授权的编译器编译 ASN.1 项目时，以下信息可能会被传输至我们的许可服务器以进行许可证验证和信封签名：

  • 证书序列号
  • 产品标识符
  • 机器指纹（可选）
  • 客户端 IP 地址

3. 我们如何使用您的信息

3.1 购买处理

  • 创建和管理您的客户账户及订单记录。
  • 签发和管理许可证证书及关联的 PKCS#12 凭证文件。
  • 生成有时限的下载令牌以交付许可证。
  • 将许可证凭证和说明发送至您的电子邮箱。
  • 就订单状态与您进行沟通。

3.2 免费试用处理

免费试用申请采用临时处理方式。我们为您生成 30 天试用证书并发送至您的电子邮箱。我们不会将免费试用申请数据持久化存储到数据库中——不会为免费试用申请创建客户记录、订单记录、证书记录或许可证文件记录。

3.3 许可证验证

编译日志（证书序列号、产品 ID、机器指纹、客户端 IP）会被收集用于许可证验证和反盗版目的。这些日志用于验证许可证是否在授权范围内使用。

3.4 通信

我们可能会使用您的电子邮箱地址来：

  • 发送许可证文件和下载说明。
  • 发送订单确认和状态更新。
  • 回复您的支持咨询。

4. 数据存储与保留

4.1 购买数据

购买相关数据（客户信息、订单记录、证书记录和许可证文件）存储在我们的数据库中，并在您的许可证有效期加上合理的后续期限（用于法律和会计目的）内保留。

4.2 免费试用数据

免费试用申请数据不会持久化存储在我们的数据库中。这些信息仅用于生成和发送您的试用许可证，并在邮件发送后被丢弃。

4.3 编译日志

编译日志在与相关许可证有效期相同的期限内保留，用于审计和合规目的。

5. 第三方服务

5.1 Stripe（支付处理）

我们使用 Stripe 处理许可证购买的支付。当您提交订单时，您的支付信息会直接传输至 Stripe。Stripe 对您个人信息的使用受其自身隐私政策的约束，详情请见 stripe.com/privacy。

5.2 邮件投递

我们使用基于 SMTP 的邮件投递服务来发送许可证文件和通信。邮件发件地址为 noreply@asnlab.org。

6. 数据共享

我们不会出售、出租或交易您的个人信息。我们仅在以下情况下共享您的信息：

  • 为提供我们的服务而必要的第三方服务提供商（如 Stripe 和我们的邮件基础设施）。
  • 法律要求或为回应法律程序。
  • 为保护我们的权利、财产或安全，以及我们用户的权利、财产或安全。

7. 安全措施

我们采取合理的技术和组织措施来保护您的个人信息：

  • 许可证证书使用 RSA-4096 加密技术签发。
  • 管理 API 端点通过 API 密钥认证进行保护。
  • 客户数据库访问仅限于授权人员。
  • PKCS#12 文件使用随机生成的凭据进行密码保护。

8. 您的权利

根据您所在的司法管辖区，您可能享有以下权利：

  • 访问我们所持有的关于您的个人数据。
  • 要求更正不准确的数据。
  • 要求删除您的数据。
  • 反对或限制某些处理活动。
  • 数据可携带性。

如需行使上述任何权利，请通过以下电子邮箱与我们联系。

9. 联系我们

如果您对本隐私政策有任何疑问，或希望行使您的数据权利，请联系我们：

  • 电子邮箱：sales@asnlab.org
  • 网站：asnlab.org

10. 本政策的变更

我们可能会不时更新本隐私政策。变更内容将发布在此页面上，并附有更新的生效日期。我们建议您定期查阅本政策。
