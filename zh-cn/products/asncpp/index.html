ASN.1 C++ 编译器

现代 C++ 代码生成，由您选择内存模型和标准。

ASN.1 C++ 编译器生成地道且犹如手写的 C++ 类。选择您的 C++ 标准、内存管理策略和类型映射 —— 编译器适配您的代码库，而不是反过来。

C++03 或 C++17，由您决定。 针对遗留代码库使用 C++03 联合体，或启用 C++17 以获得基于 std::variant 的 CHOICE 类型和现代语言特性。生成的代码与您指定的标准相匹配。

适合您架构的内存管理。 使用原始指针实现最小开销，使用 unique_ptr 实现清晰的拥有权语义，或使用 shared_ptr 实现共享生命周期。OPTIONAL 字段映射到您选择的指针类型 —— 没有妥协。

智能默认值，完全可控。 开箱即用，编译器会选择适合约束条件的最小整数类型，将类型包装在模块命名的命名空间中，并生成清晰的析构函数。当您需要精确控制时，每个映射都可配置。

七种编码规则，同一套 API。 BER、DER、UPER、APER、OER、XER 和 JER 都通过一致的编码/解码接口提供。用一个规则测试，用另一个规则部署。
