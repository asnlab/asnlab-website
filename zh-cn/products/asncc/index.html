ASN.1 C 编译器

从您的 ASN.1 规范生成紧凑、可移植的 C 代码。

ASN.1 C 编译器将您的协议定义转化为清晰、可读的 C 结构体，可在任何平台上编译。无论您是面向资源受限的微控制器还是高吞吐量的服务器，生成的代码都会针对您的环境进行优化。

一次编写，随处部署。 生成的 C 代码除了紧凑的运行时库外没有外部依赖。它可使用任何符合标准的 C 编译器编译，并在 Linux、Windows、macOS 和嵌入式目标上运行。

天生具有平台感知能力。 告诉编译器您的目标平台的整数大小，它会为每个 ASN.1 INTEGER 选择最优的 C 类型 —— 从单字节到任意精度的大整数。由您来控制映射，而不是反过来。

您需要的所有编码规则。 BER、DER、UPER、APER、OER、XER 和 JER 都通过同一套简洁的 API 提供支持。无需更改应用程序代码即可切换编码规则。

按需选配的额外功能。 生成约束验证函数，以在边界处捕获格式错误的数据。添加相等比较、打印函数或示例测试框架，只需一个配置开关。不会强制任何内容进入您的构建。
