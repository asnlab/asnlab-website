ASN.1 Go 编译器

从 ASN.1 生成原生 Go 结构体，具备 Go 开发者期望的简洁性。

ASN.1 Go 编译器生成整洁的 Go 结构体，感觉就像地道的 Go 代码。将生成的包与运行时库一起导入，即可使用标准方法调用进行编码和解码。

Go 原生的类型映射。 根据您的约束和偏好，INTEGER 变为 int64、int32 或 *big.Int。REAL 映射到 float64 或 float32。没有包装器，没有适配器 —— 只有 Go 类型。

每个模块一个包。 每个 ASN.1 模块生成自己的 Go 包。像导入模块中的任何其他包一样导入它，并使用编码规则常量调用 Encode 和 Decode。

可选的便捷方法。 生成 Equals 方法用于深度比较，生成 String 方法用于调试输出。通过配置开关启用您需要的功能。

七种编码规则，零摩擦。 BER、DER、UPER、APER、OER、XER 和 JER 支持内置于运行时中。您生成的类型通过同一接口支持所有编码规则。
