ASN.1 Java 编译器

从 ASN.1 生成地道的 Java 类，运行时专为性能打造。

ASN.1 Java 编译器生成的 Java 源代码能自然融入任何 JVM 项目。将运行时 JAR 放入类路径即可开始编码和解码 —— 无需脚手架、无需代码生成守护进程、没有意外。

在 Java 中有意义的类型。 INTEGER 约束自动选择 BigInteger、long、int 或 short。ENUMERATED 类型变成 Java 枚举或可扩展的基于类的常量。SEQUENCE OF 映射到 ArrayList、LinkedList、Vector 或普通数组。生成的代码读起来就像是为您的项目量身定制。

包结构尽在掌握。 模块名称自动转换为小写 Java 包。添加包前缀即可将生成的代码放入您现有的项目层次结构中 —— 例如 com.yourcompany.protocols.myprotocol —— 无需手动重构。

可选的 JavaBean 支持。 独立开关 getter 和 setter、equals 和 hashCode、clone 以及 toString 的生成。添加您的团队需要的功能，去掉不需要的。

完整的编码规则支持。 BER、DER、UPER、APER、OER、XER 和 JER。运行时处理复杂性；您的代码只需调用 encode 和 decode 并传入编码规则常量即可。
