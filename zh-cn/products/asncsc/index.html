ASN.1 C# 编译器

从 ASN.1 生成整洁的 C# 类，随时可用于您的 .NET 解决方案。

ASN.1 C# 编译器将协议规范转化为结构清晰的 C# 类，无缝融入 .NET 项目。添加运行时 DLL，引用生成的命名空间，然后开始编码。

尊重 C# 约定。 模块名称转换为小写命名空间。可选的命名空间前缀让您可以将生成的类型精确放置在架构期望的位置 —— 例如 MyCompany.Protocols.V2X。

开箱即用的值类型语义。 生成的类型默认包含 Equals 和 GetHashCode 重写。像比较任何其他 .NET 值对象一样比较协议消息。

属性或字段，由您选择。 生成带有 getter 和 setter 的规范 C# 属性，或保持更轻量的公共字段风格。独立开关 Clone 和 ToString 的生成。

您信赖的编码规则。 BER、DER、UPER、APER、OER、XER 和 JER —— 全部通过相同的 Encode 和 Decode 方法。运行时库处理线格式；您的应用程序处理业务逻辑。
