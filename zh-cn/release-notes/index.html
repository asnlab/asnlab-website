版本发布说明

ASN.1 SDK 各版本的更新内容（当前以英文呈现）。

ASN.1 SDK v3.14.15_r20261015

发布于 2026-10-15

asncpp runtime and codegen fixes: AVN/JER/constraint parity, DEFAULT back-fill, decode-depth guard, and mapping options.

  • asncpp runtime — AVN, JER, and constraint-handling fixes aligned with the other runtimes; DEFAULT values back-filled for absent BER SEQUENCE/SET members; a raised decode-depth limit with a new DECODE_DEPTH_EXCEEDED error.
  • asncpp codegen — integer/real mapping options honored correctly with INTEGER overflow fixed; list-alias and composite-alias member headers fixed.

ASN.1 SDK v3.14.15_r20261003

发布于 2026-10-03

BER extension-additions correctness, open-type/AVN changes, and table-constraint selector fixes.

  • BER extension additions — emitted in ascending component order; extension-addition groups are no longer all-or-nothing on encode; multi-octet context tags keep auto-tag numbers ≥ 31 unique.
  • Open type — CONTAINING keyword dropped in favor of inlined AVN contained values; formal (dummy) parameters tagged explicitly under AUTOMATIC TAGS.
  • Table constraints — table-constraint selectors encoded with the class-field type.

ASN.1 SDK v3.14.15_r20260921

发布于 2026-09-21

OER integer correctness, EXCEPT constraints, INTEGER named numbers, config-home support, and encoding fixes.

  • OER integers — extensible INTEGERs now encode as signed values and sign octets are stripped correctly from variable-length unsigned values across runtimes.
  • EXCEPT (Difference) constraints — mirrored across the C++, C#, and Go runtimes.
  • Open types — PER open-type (CONTAINING) CONTENT fragmentation mirrored across runtimes; parameterized inner-type CONTAINING materialized per site.
  • INTEGER named numbers — carried into runtime metadata and AVN; named BIT STRINGs rendered as named-bit lists.
  • Configuration — ASNSDK_CONFIG_HOME env var supported for the SDK config directory.
  • Extension additions — absent mandatory extension additions elided via the nullable-extension-additions option (asncsc, asncpp).
  • SET OF encoding — OER SET OF values canonicalized for round-trip consistency.

ASN.1 SDK v3.14.15_r20260908

发布于 2026-09-08

Semantic-constraint metadata end-to-end, AVN CONTAINING support on more runtimes, and DER/decode error fixes.

  • Semantic constraints — runtime metadata enriched with a full semantic-constraint payload across Java, C++, C#, and Go; WITH COMPONENTS presence constraints honored end-to-end.
  • AVN CONTAINING — open-type CONTAINING encoding ported to the C runtime, and then to the C++, C#, and Go runtimes.
  • DER decode — bit strings re-padded to their SIZE bound on decode in asncpp.
  • Errors — descriptive AtNotation errors reported instead of a generic table-constraint failure.

ASN.1 SDK v3.14.15_r20260826

发布于 2026-08-26

Parser and core fixes for value bounds and list size constraints, plus CLI update notifications.

  • Parser — Word-invisible Unicode characters (for example NBSP) are now treated as whitespace.
  • Core — deferred value-reference INTEGER and size-bound resolution, and SEQUENCE OF / SET OF size constraints preserved in compiled metadata.
  • CLI — asndt now notifies you when a new version is available.

ASN.1 SDK v3.14.15_r20260824

发布于 2026-08-24

Fixed-type table constraints, BER/CER open-type correctness, and refined OER integer encoding.

  • Fixed-type table constraints — member-row selection support added to the asnjc, asncpp, asncsc, and asngc plugins and runtimes.
  • BER open-type fixes — a shared OCTET/BIT STRING codec with open types, correct CER segmentation for BER open types, and contained-value decoding across runtimes.
  • OER integers — value-based unsigned octet counts and a fix for zero-length unaligned constrained integers across runtimes.

ASN.1 SDK v3.14.15_r20260818

发布于 2026-08-18

Semantic-model fixes for deferred resolution, new generate-contained open-type support, and runtime label/comment metadata.

  • Core semantic fixes — requeue object-set references that aren’t yet resolvable, empty-set and union object-set handling, parameterized-type parent scoping, cross-module value-type resolution, and the implicit-parameter reference (@.id) correction.
  • generate-contained — new option enabling CONTAINING open-type support for the C, C++, and C# plugins, including per-component CONTAINING inside WITH COMPONENTS.
  • Runtime metadata — label/comment metadata for components, alternatives, and extension-addition types across the Java, C++, and C# runtimes.

ASN.1 SDK v3.14.15_r20260807

发布于 2026-08-07

New clean subcommand, generated-code API alignment, license migration path, and core/encoder fixes.

  • CLI — new asndt clean subcommand.
  • Generated-code alignment — open-type variant handling, CHOICE constructors, and standalone SEQUENCE OF / SET OF wrappers aligned across Java, C, C++, C#, and Go.
  • Licensing — a license-migration path for existing customers to move to the current activation model.
  • Compiler config — a new product-id field matches a license product instead of by language.
  • Core fixes — table-constraint resolution for enriched class-field types and a null-pointer fix in the C generic encoder.

ASN.1 SDK v3.14.15_r20260724

发布于 2026-07-24

C++ codegen fixes for CHOICE/UNION mapping.

  • C++ codegen — CHOICE/UNION mapping fixes: copy/move constructors and destructors generated for mapped union choices, and a UnionChoiceConverter double-indirection bug fixed.

ASN.1 SDK v3.14.15

发布于 2026-01-16

The foundational release of the unified ASN.1 SDK: core engine, five compiler plugins, runtimes, CLI, and licensing.

The founding release establishes the complete ASN.1 development toolchain.

  • Core engine — project-based ASN.1 project model (asn1.avn), semantic model, builder, and the asndt CLI (create / compile / license).
  • Compiler plugins — full code generators for Java, C, C++, C#, and Go, each with a matching runtime library.
  • Runtimes — PER, BER, and OER codecs plus constraint evaluation across all five target languages.
  • Licensing — per-product activation with a straightforward asndt license workflow.
